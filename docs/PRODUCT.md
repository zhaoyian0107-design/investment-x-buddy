# 产品决策与验收标准

## 目标用户与主问题

有基本财务知识的个人投资研究者，需要比较公司、核查假设、保存研究进展。用户需要知道一条解释依赖什么，以及研究中断后能否继续。

## 范围选择

年度经营质量比较能够对齐报告期，建立确定性算式，并引出营运资本、季节性与业务结构等替代解释。以单研究 Agent 与持久化运行器交付闭环，避免分散于多个无完整主链路的角色。

## 信息架构

- 研究项目：目标、计划版本、阶段状态。
- 研究计划：可编辑对象、年度、截止日、指标、公开材料、预算与确认。
- 研究成果：事实表、归纳、假设、支持引用、反证、缺口、后续问题。
- 证据抽屉：来源、公开／采集时间、字段、单位、记录 ID、原始记录与算式依赖。
- 运行记录：任务尝试、失败、压缩、检查点、预算与恢复事件。
- 完成检查：逐项区分已达成、未达成与不支持；允许修改已注册完成标准。
- 判断变化：核心假设、核查条件、原文关系、修订前后与未覆盖范围。
- 长期记忆：用户明确确认的偏好和待核查假设。
- 能力与数据：工具注册、权限、超时与可用状态。

## 核心验收

| 用户动作             | 预期结果                                   |
| -------------------- | ------------------------------------------ |
| 输入具体研究问题     | 生成可编辑范围与完成标准                   |
| 未确认计划           | 不取数                                     |
| 修改计划或预算       | 旧授权不继续生效                           |
| 点击指标和引用       | 能回到原始字段及算式                       |
| 数据缺失             | 展示缺口；不补零                           |
| 请求越界建议         | 拒绝并引导回证据研究                       |
| 接口失败             | 限次重试、阶段成果、显式原因               |
| 暂停或重启           | 已提交结果继续有效                         |
| 拒绝扩展预算         | 不发生额外授权调用                         |
| 保存记忆后新建项目   | 读取偏好，保留假设身份                     |
| 导出成果             | 包含数据模式、来源索引与判断边界           |
| 并发追问消耗最后预算 | 供应商只收到一次请求，另一请求明确停止     |
| 请求中途进程退出     | 已发生调用仍收费；未知费用明确标记         |
| 收到限制材料         | 假设收窄；无关材料不挂入反证引用           |
| 用户纠正             | 近期对话可继续，纠正保留未验证身份         |
| 下载证据包           | 无数据库／API Key 也能检查引用、原文和算式 |

## 动态 UI

组件由结构化任务与成果驱动。存在财务字段时展示比较表，存在算式时展示依赖；缺字段显示缺口，存在审批时展示确认卡。模型不直接生成可执行前端代码。

## 产品评估指标

第二版优先观察完成标准达成情况、关键数字可追溯率、调用账本完整性、中断后已提交任务复用、针对核心判断的核查覆盖和修订、异常解释、越界输出拦截。还没有真实用户样本，不能给出使用率或节省时间的虚构结论。默认推荐两家公司比较，便于在两项核查上限内形成完整主链路。
