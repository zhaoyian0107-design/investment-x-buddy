# 第二版演示与讲解提纲

`outputs/v2-demo.webm` 为本轮实际录制的127.63秒无声视频。下面是讲解顺序，时间可按录制画面调整。

1. 输入比较美的与格力现金利润比、核查持续性的研究目标。说明数据和原文都是构造样本。

2. 检查范围、年度、截止日与四类完成标准。加入营业收入指标，展示必须保存新版本、重新确认才能执行。

3. 确认后展示完成检查、事实表和变化率。点击现金利润比，再点击经营现金流依赖，查看原始元字段、公开时间、内容身份与来源。

4. 打开限制材料原文，说明它为何收窄持续改善假设；无关新品材料另列。查看判断修订前后及研究局限。

5. 展示运行记录和独立调用账本。说明演示工具为构造模拟；真实请求的 Token、费用和未知状态分别记录。

连续追问、用户纠正、长期记忆、窄屏和刷新已另做浏览器验证。真实进程中断、并发预算和接口异常由自动化验证，不声称它们全部包含在这段视频中。

不要把演示模式称作真实市场研究，不声称使用未连接的 iFinD 或真实模型。
