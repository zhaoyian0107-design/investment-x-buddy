`tests/claims.test.ts`、`tests/context.test.ts`、`tests/migrations.test.ts`：中文金额／比例和过度确定性拦截；语义摘要与版本隔离；旧授权撤销、历史用量保留、旧验证降为未检查。

## 可复现故障

在新建计划的高级设置中选择一个明确标注场景并保存：

| 场景         | 预期                                |
| ------------ | ----------------------------------- |
| 公告超时     | 一次重试后记录缺口；可重试缺失任务  |
| 财务字段缺失 | null 保留，不补零、不生成无依据比值 |
| 单位冲突     | 阻止使用该任务数据                  |
| 模型失败     | 显示 fallback，保留事实与局限       |
| 中途中断     | paused；已成功财务任务和检查点保留  |
| 数据过期     | 明确缺口，不能显示为正常实时结果    |

为了演示预算停止，可在确认前将工具尝试设为1。停止后申请扩展，未批准时调用数不变化。
